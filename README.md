## 2. Mục tiêu thực hiện

Thực hiện ba bài Lab nhằm củng cố kiến thức và kỹ năng sử dụng JavaScript trong phát triển ứng dụng web. Thông qua các bài thực hành, sinh viên làm quen với cú pháp JavaScript, cách xử lý dữ liệu, thao tác với cấu trúc HTML thông qua DOM, xử lý sự kiện và sử dụng thư viện jQuery để xây dựng các chức năng tương tác trên website.

Bên cạnh đó, bài thực hành giúp nâng cao khả năng đọc hiểu mã nguồn, kiểm tra và khắc phục lỗi, tổ chức mã nguồn cũng như triển khai website bằng GitHub Pages.

## 4. Nội dung các bài Lab

### Lab 08 – JavaScript 1: Language Foundations

Tìm hiểu các kiến thức nền tảng của JavaScript, bao gồm:

- Cách nhúng JavaScript vào HTML và liên kết tệp JavaScript bên ngoài.
- Sử dụng biến, kiểu dữ liệu và các đối tượng có sẵn.
- Thao tác với String, Date, Array và Object.
- Xây dựng và sử dụng Functions.
- Làm quen với Browser Console để kiểm tra và gỡ lỗi chương trình.

### Lab 09 – JavaScript 2: DOM and Events

Tìm hiểu cách JavaScript tương tác và thay đổi nội dung trang web thông qua DOM, bao gồm:

- Truy xuất và lựa chọn các phần tử HTML.
- Tìm hiểu mối quan hệ giữa các nút trong DOM.
- Thêm, xóa và chỉnh sửa các phần tử HTML.
- Xử lý các sự kiện người dùng như click, mouseover và mouseout.
- Làm việc với Form và kiểm tra dữ liệu đầu vào.
- Kiểm tra và gỡ lỗi trong quá trình xử lý sự kiện.

### Lab 10 – JavaScript 3: jQuery

Làm quen với thư viện jQuery và ứng dụng vào thao tác trên website, bao gồm:

- Cài đặt và thiết lập thư viện jQuery.
- Sử dụng Basic Selectors và Advanced Selectors.
- Xử lý sự kiện bằng jQuery Listeners.
- Thêm và thao tác các phần tử DOM.
- Xây dựng hiệu ứng và hoạt ảnh bằng jQuery.
- Thực hiện GET Requests và xử lý kết quả thông qua jqXHR.
